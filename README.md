# Laporan Praktikum Lab4Web

## 1. Tujuan Praktikum

Praktikum ini bertujuan untuk mempelajari penggunaan HTML dan CSS dalam pembuatan elemen kotak, navigasi, layout website, sidebar, dan konten artikel.

## 2. Langkah Pengerjaan

### Langkah 1: Membuat Box Element

Membuat tiga elemen div dengan warna berbeda menggunakan properti CSS `float` dan `padding`.

![Box Element](screenshot/01-box-element.png)

### Langkah 2: Mengatur Clearfix

Menambahkan kotak keempat dan menggunakan properti `clear` agar posisinya berada di bawah kotak sebelumnya.

![Clearfix](screenshot/02-clearfix.png)

### Langkah 3: Membuat Layout

Membuat struktur website menggunakan header, navigasi, hero panel, main content, sidebar, dan footer.

![Layout](screenshot/03-layout.png)

### Langkah 4: Membuat Navigasi

Mengatur menu navigasi dengan warna latar biru, tulisan putih, dan efek hover.

![Navigasi](screenshot/04-navigasi.png)

### Langkah 5: Membuat Hero Panel

Menambahkan judul, deskripsi, dan tombol pada area hero panel.

![Hero Panel](screenshot/05-hero-panel.png)

### Langkah 6: Membuat Sidebar dan Konten

Membuat area konten utama, widget sidebar, kartu informasi, dan artikel.

![Sidebar dan Artikel](screenshot/07-artikel.png)

### Langkah 7: Membuat Halaman About

Membuat halaman yang berisi profil, deskripsi, dan portofolio.

![About](screenshot/08-about.png)

### Langkah 8: Membuat Halaman Contact

Membuat formulir kontak dengan kolom nama, email, dan pesan.

![Contact](screenshot/09-kontak.png)

### Langkah 9: Validasi HTML

Memeriksa dokumen HTML menggunakan W3C Validator dan memperbaiki kesalahan yang ditemukan.

![Validasi](screenshot/10-validasi.png)

## 3. Kesimpulan

Melalui praktikum ini, saya mempelajari penggunaan HTML dan CSS untuk membangun layout website sederhana, mengatur posisi elemen, membuat navigasi, dan menyusun konten halaman web.
